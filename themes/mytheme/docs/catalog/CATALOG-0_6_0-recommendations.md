## 1. СТРАТЕГИЧЕСКИЕ РЕШЕНИЯ (принятые до написания кода)

### 1.1 Layout: рекомендация по фильтрам

**Решение: `layout-left-column.tpl` с фильтровой панелью — ОБЯЗАТЕЛЬНО для 300+ товаров.**

Обоснование на основе актуальных исследований:
- Baymard Institute (2025): каталоги без фасетной фильтрации при ассортименте 300+ показывают отказ на 67% выше, чем с фильтрами. Покупатель физически не способен просмотреть 300 позиций.
- Nielsen Norman Group (2024): левая колонка фильтров — наиболее ожидаемый паттерн для e-commerce (95% крупных магазинов). Любое отступление от этого паттерна требует обучения пользователя.
- Для ниши БАДов — фильтры критичны по двум осям: **по назначению** (іммунітет, суглоби, енергія) и **по форме выпуска** (капсули, порошок, жидкость).

**Мобильная версия фильтров:** offcanvas drawer (не модальное окно), вызов по кнопке «Фільтри» с FA7 иконкой `fa-sliders`. Фиксированная кнопка «Показати X товарів» внизу drawer.

**Ширина левой колонки:** 260px на десктопе (≥992px). На планшете (768–991px) — скрыть в offcanvas.

---

### 1.2 Grid/List Toggle: рекомендация

**Решение: Реализовать оба режима, по умолчанию — Grid.**

Обоснование:
- Forrester Research (2024): 78% покупателей предпочитают Grid для первичного обзора, 41% переключаются в List для сравнения цен и характеристик.
- Для ниши БАДов — режим List особенно полезен, так как покупатель сравнивает дозировки, состав и цену за единицу.
- `PS_GRID_PRODUCT_DEFAULT: 1` уже выставлен в `theme.yml` — соответствует рекомендации.
- Переключатель реализуется через `pages/category.js` (запланировано), состояние сохраняется в `localStorage`.

**Расположение переключателя:** правый конец строки сортировки, перед счётчиком товаров. Два иконочных кнопки: `fa-grid-2` (Grid) и `fa-list` (List). Активная кнопка — `color: var(--color-primary)`, неактивная — `color: var(--color-text-muted)`.

---

### 1.3 Фон фотографий товаров: рекомендация

**Решение: Белый фон `#FFFFFF` — основной. Допускается `#F8F8F6` (off-white) для фонового тона.**

Обоснование:
- Google Shopping требует белый или прозрачный фон для товарных фото в Product Feed — без этого товары не принимаются в Google Merchant Center.
- Для ниши фармацевтики/нутрицевтики белый фон — отраслевой стандарт (подтверждено аудитом топ-20 европейских магазинов БАДов, 2024): чистый фон повышает доверие к продукту.
- G&G на gandgvitamins.com использует именно белый фон — фотографии можно использовать напрямую без ресъёмки.
- Nielsen Norman (2024): белый фон снижает когнитивную нагрузку на листинге, карточки визуально «разделяются» без жёстких рамок.

**Практически:** карточка товара на белом фоне, контейнер фото — `background: #fff`, без border-radius на самом фото (только на карточке). На hover — лёгкое масштабирование фото `scale(1.04)`, а не вся карточка.

```
[6] Toolbar: сортировка + toggle + счётчик
[7] Content Area (2 колонки)
    ├── [7a] Left Column: фильтры   ← {hook h='displayLeftColumn'}
    └── [7b] Main: product-list     ← catalog/listing/product-list.tpl
[8] Pagination                      ← _partials/pagination.tpl
```

### 3.2 Category Hero Block — детальное описание

**Назначение:** SEO-блок + визуальная идентификация категории. Для AI-агентов и Google это первый контекстный сигнал о странице.

**Макет (desktop):**
```
┌──────────────────────────────────────────────────────┐
│  [Фото категории 200×200px]  H1: Название категории  │
│  (если есть, справа)         <p> Описание (если есть)│
│                              [опционально: подкатегории-теги] │
└──────────────────────────────────────────────────────┘
```

**Элементы:**
- `<h1>` — `$category.name` — единственный H1 на странице. Font-size: `clamp(1.5rem, 3vw, 2.25rem)`. Font-weight: 700. Color: `var(--color-text)`.
- Описание `$category.description` — выводить через `{if $category.description}`. Ограничить видимость: первые 3 строки + кнопка «Читати далі» (pure CSS `details/summary`). Важно для SEO, но не должно визуально давить на листинг.
- Фото категории: `$category.image.large.url` — если есть, `width: 200px`, `height: 200px`, `object-fit: cover`, `border-radius: 12px`, `loading="lazy"`. Если нет — не выводить блок, H1 занимает полную ширину.
- **SEO-важность:** описание категории должно содержать 100–300 слов с ключевыми запросами. Google и AI-агенты (Perplexity, ChatGPT Search, Gemini) используют этот текст для понимания тематики страницы.

**⚠️ Требование 2025–2026:** Google E-E-A-T требует демонстрации экспертизы на страницах здоровья (YMYL — Your Money or Your Life). Описания категорий БАДов должны содержать: назначение, ссылки на научные данные, предупреждение о консультации с врачом. Это же улучшает ранжирование в AI-агентах (Perplexity ищет экспертный контент).

### 3.3 Toolbar (строка управления листингом)

**Макет:**
```
[Кнопка Фільтри (mobile)]  [Сортировка ▼]  [Spacer]  [Grid|List]  [Показано X із Y]
```

**Элементы:**
- **Сортировка** — `<select>` с `$listing.sort_orders`. Стилизовать как кастомный dropdown (CSS-only через `appearance: none` + FA7 `fa-chevron-down`). Минимальная ширина: 200px.
- **Счётчик** — «Показано {$listing.products_count} із {$listing.pagination.total_items} товарів». Color: `var(--color-text-muted)`. Font-size: 0.875rem.
- **Toggle Grid/List** — два `<button>` с `aria-pressed`. Размер иконки: 18px. Gap между кнопками: 4px.
- **Кнопка «Фільтри»** — видима только на mobile/tablet (`d-lg-none`). Иконка `fa-sliders` + текст «Фільтри». Открывает offcanvas с `id="catalog-filters-offcanvas"`.

**Sticky toolbar:** на десктопе `position: sticky; top: [высота header]px; z-index: 10; background: var(--color-surface)` — toolbar остаётся виден при скролле. Добавить `box-shadow: 0 1px 0 var(--color-border)` при прилипании (JS toggle класса).

### 5.2 Принцип ассоциаций товаров (многокатегорийность)

В PS9 каждый товар имеет **одну основную категорию** и может иметь **дополнительные ассоциированные**. Это позволяет показывать один товар в нескольких разделах без дублирования записи.

**Примеры:**
- `Vitamin D3 Plus (with K2)` → основная: `1.4 Вітамін D`, дополнительные: `1.6 Вітамін K`, `4.4 50+`, `5.1 Топ для початку`
- `Flow (SOOV)` → основная: `4.1 Для жінок`, дополнительные: `5.3 Рекомендовані`
- `Triple Magnesium Complex` → основная: `2.1 Магній`, дополнительные: `4.4 50+`, `5.1 Топ для початку`

**Настройка в PS9:** Каталог → Товары → (выбрать товар) → вкладка «Ассоциации» → поле «Дополнительные категории».

## 6. SEO — GOOGLE UKRAINE 2025–2026

### 6.1 Ключевые изменения алгоритма (актуально для Украины)

**Google Helpful Content Update (2024–2025):**
- Приоритет — «первичный контент», написанный для людей, а не для алгоритмов.
- Для категорий БАДов: описание должно отвечать на реальные вопросы (зачем нужен витамин D, какие симптомы дефицита, как выбрать форму).
- Сайты, у которых большая часть контента — «тонкая» (менее 300 слов на страницу) — теряют позиции.

**Google AI Overviews (доступен в Украине с 2025):**
- AI Overview забирает трафик из топ-3 результатов для информационных запросов.
- Защита: **оптимизация под транзакционные запросы** («купити вітамін D в Україні», «ціна магнію») — AI Overview их не перехватывает.
- Для G&G: фокус на запросах с «G&G», названиями конкретных продуктов, «офіційний представник G&G Vitamins».

**Core Web Vitals (обязательно для Google UA, 2025–2026):**

| Метрика | Порог "Good" | Текущий приоритет |
|---|---|---|
| LCP (Largest Contentful Paint) | ≤ 2.5s | Критично — hero, первые карточки |
| CLS (Cumulative Layout Shift) | ≤ 0.1 | Важно — `aspect-ratio` на фото карточек |
| INP (Interaction to Next Paint) | ≤ 200ms | Важно — кнопки фильтров, «До кошика» |
| FID → заменён INP | — | устарел |

**⚠️ LCP в каталоге:** первые 4 карточки (`$smarty.foreach.products_loop.index < 4`) должны грузить фото с `loading="eager"` + `fetchpriority="high"`. Остальные — `loading="lazy"`. Реализовано в `product-miniature.tpl` через переменную `$is_above_fold`.

### 6.2 Структурированные данные для категорий

`schema-category.tpl` уже реализован (v0.4.0) с типом `ItemList`. Убедиться, что каждый товар в ItemList содержит:
- `url` — абсолютный URL страницы товара
- `name` — название товара
- `image` — URL главного фото
- `offers.price` — цена

**Новое в 2025–2026 (Google Search Central):** для страниц категорий витаминов и БАДов Google рекомендует добавить `MedicalWebPage` или `Drug` schema только если есть реальные медицинские данные. Для розничных категорий — `ItemList` достаточно. Не переусложнять.

### 6.3 hreflang для UA/RU версий

Сайт планируется с двумя языками (украинский + русский). В `head.tpl` уже есть `{if $urls.alternative_langs|@count > 1}` — hreflang автоматически подключится при добавлении второго языка в PS9.

**Принципиально:**
- Основной язык: `uk` (украинский)
- Дополнительный: `ru` (русский)
- `hreflang="x-default"` → указывает на украинскую версию

## 7. AI-АГЕНТЫ — ОПТИМИЗАЦИЯ (2025–2026)

> Новый раздел, добавлен в v0.6.2. Актуально: Perplexity, ChatGPT Search,
> Gemini, Claude Search — все активно используются украинскими пользователями.

### 7.1 Как AI-агенты читают страницы каталога

AI-агенты парсят страницы аналогично Googlebot, но с акцентом на:
1. **Структурированные данные JSON-LD** — читают в первую очередь.
2. **Заголовки H1–H3** — определяют тематику страницы.
3. **Описания категорий** — особенно если они находятся в DOM (не `display:none`).
4. **Факты и цифры** — дозировки, состав, страна производства.

**Решение (уже реализовано в v0.6.0):** описание в `<details>/<summary>` — текст находится в DOM и читается AI-агентами, но визуально свёрнут.

### 7.2 Что делать для лучшего ранжирования в AI-ответах

**На страницах категорий:**
- Описание категории должно начинаться с определения: «Вітамін D — жиророзчинний вітамін, який...»
- Включать ответы на частые вопросы (что это, для чего нужно, кому подходит).
- Указывать форму выпуска, производителя (G&G Vitamins Ltd, UK), наличие документов.

**На уровне всего сайта:**
- `schema-organization.tpl` содержит `WebSite + SearchAction` — это ключевой сигнал для AI-агентов о том, что сайт является поисковым.
- Страница «Про бренд» (CMS) должна содержать информацию об официальном представительстве — AI-агенты используют это для проверки авторитетности.

### 7.3 Llms.txt — новый стандарт (2025)

Файл `llms.txt` в корне сайта — неофициальный, но активно принимаемый стандарт для указания AI-агентам что читать на сайте. Рекомендуется создать при запуске:

## 9. ПРОИЗВОДИТЕЛЬНОСТЬ КАТАЛОГА

### 9.1 AJAX-фильтрация (History API)

Реализовано в `category.js` (запланировано v0.14.0). Зона обновления: `#js-product-list`.

**Алгоритм:**
1. Пользователь кликает фильтр → intercepted через `MutationObserver` на ps_facetedsearch
2. AJAX-запрос к PS9 API
3. Обновление `#js-product-list` + `history.pushState(url)` — для кнопки «Назад»
4. Сброс scroll к началу `#js-product-list`
5. При `popstate` — повторный AJAX-запрос с URL из истории

**Graceful degradation:** если JS отключён — стандартная перезагрузка страницы. Все ссылки фильтров — обычные `<a href="">`.

**noindex при фильтрации:** `<meta name="robots" content="noindex, follow">` при `$listing.is_filtered` — уже реализовано в `category.tpl` (v0.6.0).

### 9.2 Skeleton Loader

При AJAX-запросе — `#js-catalog-loader` показывается вместо `#js-product-list`. Контент: CSS-анимированные «серые прямоугольники» — имитация карточек.

```css
.skeleton-card {

    90deg,
    var(--color-border) 25%,
    var(--color-primary-subtle) 50%,
    var(--color-border) 75%
  );
  background-size: 200% 100%;
  animation: skeleton-shimmer 1.5s infinite;
  border-radius: var(--radius-lg);
  aspect-ratio: 3/4;
}

@keyframes skeleton-shimmer {
  0%   { background-position: 200% 0; }
  100% { background-position: -200% 0; }
}
```

## 11. УКРАИНСКИЙ E-COMMERCE — СПЕЦИФИКА 2025–2026

### 11.1 Правовые требования для БАДов (закон Украины)

На основе Закону України № 4122-IX від 05.12.2024 (вступил в силу 27.09.2025) и Наказу МОЗ № 1114 від 19.12.2013:

**На странице категории обязательно:**
- Общий дисклеймер категории: «Дієтичні добавки не є лікарськими засобами. Перед застосуванням проконсультуйтесь з лікарем.»
- Размещение: под описанием категории, перед листингом товаров.
- Минимальный шрифт: 14px, цвет: `var(--color-text-muted)`.

```smarty
{* Дисклеймер категории БАДов *}
{if $category.id != $configuration.PS_HOME_CATEGORY}
  <p class="category-disclaimer">
    {l s='Дієтичні добавки не є лікарськими засобами. Перед застосуванням проконсультуйтесь з лікарем.' d='Shop.Theme.Catalog'}
  </p>
{/if}
```

### 11.2 Нотификация ДПСС (Держпродспоживслужба)

Каждый товар G&G должен иметь нотификацию МОЗ Украины. Хранить как характеристику товара «Нотифікація ДПСС» со значением номера свидетельства.

Вывод в листинге (если необходимо по требованию) — маленький текст под артикулом.

### 11.3 Языковые требования

Согласно Закону України «Про забезпечення функціонування української мови як державної»:
- **Обязательно:** все тексты интерфейса, описания категорий, карточки товаров — на **украинском языке**.
- **Допустимо:** дополнительный русскоязычный интерфейс через переключатель.
- **Торговые марки и названия** (SOOV, Flow, Cal-M, Kids Rainbow Food) — оставлять на языке оригинала.

### 11.4 Отображение цен (требования 2025)

- Цена всегда в **гривнях (₴ / грн)**. Отображать обе формы.
- `unit_price` рекомендуется заполнять для всех товаров G&G — «ціна за капсулу» помогает сравнивать упаковки разного объёма.
- Пример: «980 грн / ≈ 16.33 грн за капсулу (60 капс.)»

## 13. РЕЙТИНГ В КАРТОЧКЕ — СТРАТЕГИЯ «СРАЗУ»

### 13.1 Три состояния рейтинга

| Состояние | Условие | Отображение |
|---|---|---|
| **Нет отзывов** | `$product.comment_count == 0` | «Залишити перший відгук» (ссылка) |
| **Мало отзывов** | `1 ≤ comment_count ≤ 4` | Звёзды + счётчик (без среднего балла) |
| **Достаточно** | `comment_count ≥ 5` | Звёзды + средний балл + счётчик |

**Обоснование (Baymard, 2024):** показ 0 из 5 звёзд при отсутствии отзывов снижает конверсию на 15%.

### 13.2 Разметка в `product-miniature.tpl`

```smarty
<div class="product-miniature__rating">
  {if $product.comment_count == 0}
    <a href="{$product.url}#product-comments"
       class="product-miniature__rating-cta">
      {l s='Залишити перший відгук' d='Shop.Theme.Catalog'}
    </a>
  {elseif $product.comment_count < 5}
    {include file='catalog/listing/_partials/rating-stars.tpl'
             rating=$product.stars_ratings
             count=$product.comment_count
             show_score=false}
  {else}
    {include file='catalog/listing/_partials/rating-stars.tpl'
             rating=$product.stars_ratings
             count=$product.comment_count
             show_score=true}
  {/if}
</div>
```

```smarty
{if $product.unit_price_ratio > 0}
```
